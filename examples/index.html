@dokieli/web-access-control

A playground for Web Access Control (WAC): discover the effective ACL resource, read its authorizations, plan a change, and see the payload before it is sent.

Requires node examples/server.js, which serves this page and acts as the WAC origin: local test documents advertising Link rel="acl" and WAC-Allow, ACL resources held in memory, and PATCH over application/sparql-update or text/n3. This example page relies on the built-in Turtle parser; applications that already load a parser, or that read other serializations, pass their own as parse. New authorization identifiers are numbered rather than random so the payloads below stay readable and diffable.
